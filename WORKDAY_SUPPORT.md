# Workday Support

Workday is supported as a manual destination:

- paste the public employer posting into JobApplier;
- save the official Workday URL and a local portal note;
- score the job and prepare reviewed drafts;
- open the official URL yourself;
- complete authentication and every application field manually;
- submit only after review;
- return to JobApplier and explicitly mark the role applied.

No Workday login, scraping, form filling, sensitive-answer selection, CAPTCHA handling, or submission is automated.
